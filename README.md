# GroupsCatalog2 for OpenMage

Hide products and categories per customer group: `Netzarbeiter_GroupsCatalog2` 0.3.6 by Vinai
Kopp (OSL 3.0, https://github.com/Vinai/groupscatalog2), packaged for Composer and
OpenMage 20 / PHP 8.4.

Changes from 0.3.6: Composer package (`ysrtech/groupscatalog2`, magento-composer-installer),
EcomDev_PHPUnit tests removed.

## Settings

System > Configuration > Catalog > GroupsCatalog 2: enable per website or store view, mode
("show" = the product/category lists the groups that see it), defaults, what hidden pages do
(404, redirect, message). Per product and category: the "Customer Groups" field
(`groupscatalog2_groups`). Two indexes: GroupsCatalog Products / Categories.
